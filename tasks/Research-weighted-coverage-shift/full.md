Finish the Halstow board and hand it back as a notebook the next depot can run unchanged. The contact centre and the regional manager take two things from it: the arrival window each class prints on the crew card, and the share of jobs that window holds, to within two points.

The share is over every job the depot dispatched that month, counted as the traffic report counts them, not over the audit sheets. Those are not the same set of jobs here. The audit desk asks the close-out clerks for twelve sheets of every class every week whatever that class ran, so a class that dispatched four hundred jobs and a class that dispatched forty are both twelve sheets a week on file, and the file is nothing like the month. So carry each class at the share of the month the traffic report gives it and never at its share of the sheets, work out from that class's own rows how much of it the window printed for it holds, and put the classes back together in the traffic report's proportions. A class the board prints no window for holds none of its jobs and its jobs still count in the share, because the crew card still went out and the customer was still given a time.

One window a class, never one window over all of them. A window is a half-width on the tool's number in whole minutes, written as two edges with the low one first, so a class whose rows carry forty-seven minutes prints as minus forty-seven to forty-seven. Beside each window, report how many current rows stood behind it. The share under it is one figure to the nearest point with no range beside it.

The window a class prints is the tightest one that class's own rows carry at the board's level, and never tighter. Sort the class's rows by how far the finish landed from the tool's number and take the level over one row more than the file holds, because the window is being printed for a job that is not one of the rows behind it, so the edge sits a place up: with ninety-six rows at nine in ten that is the eighty-eighth of them, with twelve rows it is the twelfth. A class with fewer than nine rows has nothing at that level to sit on and prints no window at all. The board's level is nine finishes in ten and the contact centre will not read out a window running more than three hours end to end, so a class whose own rows will not fit inside three hours prints no window either.

The class whose pull has stopped returning is the one to read off the `sheets_returned` column of the intake log, never off a name: a class the log shows sheets pulled for and none of them returned in the last week of the audit is that class — twelve of them here, whatever that desk's pull happens to be at the next depot. Its older sheets do not print a window. They are about work the class no longer does, and a window built on them holds far less of the class than the board promises. Once the audit crew has timed jobs on it itself, the window is what those nights carry and the sheets from before do not go back in. A night the crew times on a class whose pull is still returning goes in beside that class's sheets; only the class whose pull has stopped leaves its older sheets out.

The month grants Halstow 36 audit units and four have gone. A night visit costs three and times at most six jobs of one class; because an accepted night costs the same units and roster slot however many jobs are requested, book all six places on it. The desk runs at most two nights in a week; it will only put a crew on a class in that class's rostered weeks; and it charges one unit for every request it turns away, so the balance to work the next booking out of is the grant less everything on the receipt file, refusals included. Book a class the board cannot print first. When more than one cannot print, the one that carries the bigger share of the month is the useful default, but a night on any unprintable class advances the board. Stop when every class the depot dispatches has a window, when the balance will not pay for another night, or when none of the classes still without a window has a rostered week left with a night free in it. A stop with units still in hand is an answer, not a failure.

Every request the depot was billed for appears in the board once, with its receipt id, the class it was booked on, the jobs the crew actually brought back and the units it was charged, and the units the board says are left has to be the grant less everything on that file. A refusal is a billed request like any other. A line the receipt file does not carry is not a visit.

`analysis.py` and `support.py` are the files to change. `protocol.py` is the shape the dispatch stack reads a notebook through and ships with the stack. The same notebook runs Bewick, Cranmoor, Dorley, Elverton, Fairhaven and Garrow after this one, each on its own month, its own pull, its own roster, its own grant and its own classes, and Garrow's audit desk pulls its sheets in the proportions the classes are dispatched in and has had no form change at all, so its file is already the depot, every class there prints a window, the board already holds nine in ten, and the answer there is a stop with units still in hand. Nothing in the notebook should be written for Halstow's numbers or Halstow's class names.

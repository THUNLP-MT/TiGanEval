# Incumbent module characterisation

Measured 2026-05-11 on the thermal bench by Suli Rahman.

The module was built with the spreader it ships with today (`INC`) and run at
the load point the screen uses. Four soaks, all four within a tenth of each
other.

**Case temperature rise over coolant: 18.4 K.**

That figure is the one the reporting job subtracts to fill the `score_K` column
of a screen table. It is held on the bench wiki and is re-measured when the
module build changes; the module build has not changed since May.

Rig conditions on the day: coolant set point 19.2 C, room ambient 22.8 C.
